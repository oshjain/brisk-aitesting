# Test Coverage Catalogue

This catalogue explains why each executable test exists, what evidence it uses,
what it disproves, and what it does not prove. `legacy-backfill-pending` is
existing documentation debt, not a claim that coverage is complete. New tests
must enter as `documented`.

Coverage dimensions use: `positive`, `negative`, `boundary`, `adversarial`,
`fault`, `security`, `cancellation`, `timeout`, `cleanup`, `compatibility`,
`packaging`, `reference-app`, and `cross-platform`.
